# Academic Projects

Three projects from vocational and university coursework, before Delta.

## Online Classroom Management System, Vocational Certificate, 2021

A full-stack assignment submission platform (PHP, MySQL, Bootstrap). Students join a class with a join code; teachers get grading tools and real-time visibility into who has submitted what, with an automated export to Excel for grade reporting.

## Smart Traffic Light Control System, Vocational Certificate, 2023

Led the project, set the budget and split the work across the team. Built on an Arduino Uno (C/C++) with IR sensors that detect whether a car is actually present, so the lights adjust their timing based on real traffic instead of running on a fixed cycle. Also built a companion app to monitor light status, control the lights, and check the live sensor readings. The circuit was designed and tested on a breadboard before anything went further.

## Full-Stack E-Commerce System, University Capstone, 2025

A full-stack web application (PHP/OOP, MySQL) with an AJAX shopping cart, real-time inventory sync, and a multi-level role system (Admin/Factory/Customer). Sales analytics were built with Chart.js, and the whole thing shipped with bilingual (Thai/English) support.
